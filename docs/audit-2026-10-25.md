## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| JSON 解码忽略第二个值、尾部垃圾，尾部字节未完整触发大小限制 | 解码后必须读至 EOF；回归确认分别返回 400 / 413 |
| 过滤表单输入键仍可覆盖同名未打 tag 的内部字段 | 按显式 tag 逐字段绑定，保留嵌套结构与默认值；内部字段隔离回归通过 |
| 显式空名 `form:",default=18"` 丢失默认值 | 仅显式 tag 允许回退到字段名；默认值与输入覆盖均验证 |
| 非自增主键不进入创建 DTO | 允许创建参数提供非自增主键 |
| GORM 将非自增整数主键当作自增，`/0` 被 required 拒绝 | 生成 `autoIncrement:false`；实际 MySQL 的 0 主键创建、查询、更新、删除通过 |
| SQL DEFAULT 被未传参数的零值覆盖 | 区分省略与显式零值，省略列由数据库应用默认值，主库回读响应；DEFAULT 18 与显式 0 均通过 |
| 必填布尔列无法区分省略和 false | 必填值用指针判断是否提供；省略返回 400，false 可以创建 |
| 多个 SQL 列转换成重复 Go 字段 | 在生成之前拒绝并给出冲突列名；仅 CRUD 的路径 ID 冲突不会误拒绝 model 命令 |
| 哈希碰撞下移除低权重节点可能误删其他节点并除零 panic | 记录每个实际节点的虚拟节点数量；碰撞回归通过 |
| 亚毫秒调度刻度共用毫秒锁 key | 使用纳秒刻度；100µs 间隔在 1ms 内执行 10 次的回归通过 |
| CLI 提示集中测试迁移后的空跑命令 | 成功提示改为 `make check` |
| 集成测试在关闭连接之后才删除表 | 正常与失败路径均在连接可用时清理测试表 |

上述缺陷均先观察回归失败，再修复并验证。已有未提交改动也包含在最终回归中，包括两个 main 的错误退出码、HasDir 权限错误、请求 ID、日志脱敏、资源关闭、Redis 锁及工具函数等。

- 通过 Go 原生 overlay 在原包上下文执行，保留私有函数与相对路径测试。运行器不改写生产源码，也不落盘创建旁路测试文件。
- `make test` / `make race` / `make vet` / `make tidy` 是统一入口。直接 `go test ./...`、`go mod tidy` 看不到集中测试，不能用于测试验收或整理依赖。
- 生成器副本先运行带 overlay 的 tidy，再执行 build、vet 和应用测试，防止测试依赖被移除后空跑。
- 仓库 `.gitignore` 显式取消全局 `test/` 忽略规则，保证测试可随提交交付。详细命令见 [test/README.md](../test/README.md)。

## 能力边界

- 漏洞库中的 GO-2026-5932 针对不维护的 `golang.org/x/crypto/openpgp`，当前项目没有导入该包，公告没有修复版本。依赖模块含公告与项目调用可达漏洞是不同结果，不能把它写成所有依赖均无公告。
- 生成器提供通用开发骨架。认证、权限、租户隔离、业务事务与幂等需按业务设计；当前生成路由未内置这些策略。
- Update DTO 的 null 表示不修改；清空列为 SQL NULL 需要额外参数语义。非自增主键需由调用方提供；数据库生成字符串主键的回填不在通用生成器能力内。
- 多主/从库集成使用同一 MySQL 实例的多连接验证路由，没有模拟实际复制延迟和跨机故障。Redis Cluster/Sentinel 与 RocketMQ 没有做真实集群验收。
- 分布式锁受 TTL 与时钟偏差约束；业务副作用仍需幂等。任务/资源关闭必须响应 context，无法强制终止忽略取消的函数。
- 本次未修改全局 shell 配置；扫描器安装在临时目录。Compose 开发依赖由本轮启动，保留用于继续开发。
